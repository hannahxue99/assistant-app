# 私人助手

## 像秘书一样帮你料理当下，像导师一样帮你看清方向

生活里真正消耗人的，往往不是某一件大事，而是无数没有被妥善安放的小事：想做却怕忘记的事、持续推进却散落各处的进展、反复出现却没有被看见的困惑，以及那些很重要、但总被眼前事务挤到后面的方向。

私人助手希望成为一个长期陪伴你的 AI。它不只是回答问题，也不只是替你记东西。它理解你正在经历什么，接住当下的琐碎，保留事情的来龙去脉，并在时间累积之后，帮助你看见其中的联系与意义。

## 一个助手，两种尺度

**像秘书一样料理当下。**

把说过的话变成可以继续推进的事情，记住承诺、安排和进展，在需要的时候找到它们、更新它们。让人不必把注意力持续花在“别忘了”和“接下来做什么”上。

**像导师一样看清方向。**

在足够理解你的前提下，连接过去和现在，识别反复出现的模式、被忽略的矛盾和真正重要的选择。它不替你做决定，而是在合适的时候，帮助你提出更好的问题。

秘书与导师不是两个角色，也不是两种需要切换的模式。它们是同一个助手面对不同时间尺度的两种能力：一边照顾今天，一边理解你要去哪里。

## 从对话，走向长期理解

人与生活不会天然以文件夹、表格和标签的方式出现。很多重要信息，最初只是一句随口说出的话。

因此，私人助手从自然对话开始。你不需要先判断一句话是待办、记录、计划还是感受，也不需要维护一套复杂的整理方法。助手负责理解其中的行动、事情、关系和长期意义，让零散表达逐渐形成一份持续更新的生活上下文。

这份理解不是静态档案。新的经历会补充它，新的决定会改变它，过时的认识可以被纠正或忘记。助手真正记住的，不只是发生过什么，还有哪些事情仍在继续、什么对你重要，以及怎样的帮助更适合你。

## 在正确的时刻，做正确的事

好的个人助手不应该不断制造提醒，也不应该为了显得聪明而随意解读用户。

它应该在需要执行时可靠，在没有新价值时保持安静；能主动发现遗漏和关联，也尊重人的节奏与判断。主动不是更频繁地打扰，而是在信息真正形成新意义时，让重要的事情重新浮现。

我们希望它最终形成这样的循环：

`表达 → 理解 → 行动 → 沉淀 → 连接 → 看见 → 再次行动`

每一次对话都不只是结束在一次回复里，而是让未来的理解和行动变得更准确。

## 值得信任，才能长期陪伴

长期理解必须建立在信任之上。

- 用户始终拥有自己的信息和最终决定权。
- 助手可以提出建议，但不能把猜测当成事实。
- 改变用户数据的行为必须明确、可追溯，也应当可以撤销。
- 记忆应该服务于用户，而不是把人固化成一份永远不变的画像。
- 外部信息可以扩展视野，但不能越过用户意愿替用户行动。

私人助手的目标不是接管生活，而是减少生活中的认知负担，让人把更多注意力留给真正重要的关系、选择和创造。

## 产品形态

- **首页**承接当下：此刻有哪些事情值得关注。
- **小知**承接交流：所有表达、追问和推进都从同一段关系继续。
- **我的**承接理解：你可以看到并修正助手对你的长期认识。

三个入口共同服务于一个目标：让今天的行动与长期的方向不再彼此割裂。
