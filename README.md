# 私人助手

**一个长期懂你的私人 AI：像秘书一样帮你料理当下，像导师一样帮你看清方向。**

大多数 AI 对话结束后，信息就留在聊天记录里；普通待办和笔记虽然能保存信息，却不理解事情之间的关系。

私人助手希望把这两件事连起来：用户只需要自然地说，小知负责理解、执行和持续整理，让零散表达逐渐形成可以继续推进的生活上下文。

## 核心闭环

`自然表达 → 理解意图 → 安全执行 → 结构化沉淀 → 持续理解 → 复盘发现 → 回到对话推进`

这不是一次性的“问一句、答一句”，而是一条长期循环：

1. 用户用自然语言说出记录、安排、进展或困惑。
2. 小知结合当前对话和已经保存的信息理解真正意图。
3. 需要行动时，小知提出操作，系统校验无误后再执行。
4. 有长期价值的内容沉淀为待办、事件或长期记忆。
5. 以后再谈到相关事情时，小知能够延续之前的上下文。
6. 当积累的信息产生新的关联、遗漏或启发时，再回到对话中帮助用户推进。

## 三个入口

- **首页**：回答“现在值得关注什么”。这里呈现近期行动和正在推进的事情。
- **小知**：统一的对话与执行入口。用户不需要先判断内容应该记到哪里。
- **我的**：回答“它已经懂我什么”。这里呈现长期记忆以及用户可以控制的能力。

三个入口不是三套独立功能。首页和“我的”展示的是小知从长期对话中沉淀出的结果，所有事情最终都可以回到同一条对话继续处理。

## 四类信息

| 类型 | 回答的问题 | 例子 |
|---|---|---|
| 对话消息 | 当时说了什么 | 一次完整表达、追问和回复 |
| 待办 | 接下来要做什么 | 周五交材料、下月还款 |
| 事件 | 一件持续的事进展如何 | 一次旅行、孩子入学、长期项目 |
| 长期记忆 | 未来应该怎样理解我 | 稳定偏好、原则、目标和重要关系 |

四类信息彼此关联，但不互相替代。同一句话可以形成待办、更新事件，也可以成为长期记忆的依据；完整表达仍然保留在对话中。

## 小知如何工作

小知既是秘书，也是导师，但不是两个需要切换的角色。

- **秘书能力**负责记录、安排、查找、更新和跟进具体事务。
- **导师能力**负责连接历史、识别模式、发现遗漏，并在真正有新价值时提出问题或建议。

模型负责理解和提出建议，本地系统负责判断这些建议能否执行。任何会改变用户数据的操作，都必须基于真实信息并通过本地校验；完成后给出明确回执，也允许撤销。

联网信息只用于帮助回答，不会在同一轮悄悄修改用户的待办、事件或记忆。模型或网络失败时，用户原话仍然保留，未完成的操作不会被描述成成功。

## 当前阶段

当前版本已经建立了连续对话、待办、事件、长期记忆和安全执行的基础闭环，小知能够读取真实数据、延续上下文，并通过联网搜索补充外部信息。

完整 V1 还需要补上主动导师闭环：统一的当前状态、每日复盘、克制的教练提醒，以及覆盖四类信息的统一搜索。
