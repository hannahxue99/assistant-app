折角卡 · 二代

最稳 · 保留存量认知

论点：办完的卡片，被折角归档。不换隐喻、不换识别度，只修三处硬伤：底色从纯白加深为深纸（白壁纸上不再「消失」）、勾形加粗到 92（29px 位仍可辨）、卡上补两行摘要灰条让「备忘卡」身份更实。

优势

  • 老用户零迁移成本，商店替换无感知断层
  • 形体只有卡 + 折角 + 勾三个元素，小尺寸天然稳
  • monochrome 派生最容易（勾的剪影）

风险

  • 与系统「备忘录」类 App 撞脸的风险仍在
  • 是「改良」不是「重设计」，惊喜感最弱

一勾即安

推荐 · 最强主张

论点：焦虑被一笔划掉。整张画布就是一页备忘纸——四条极淡的横格线交代「纸」的身份，一枝粗壮的橙勾占满画面。别的待办 App 的勾待在按钮里，这张图标里的勾「已经打完了」：产品给用户的正是那个落勾瞬间的安心。

优势

  • 29px 位只剩「纸底 + 橙勾」两个信息，缩放最稳
  • 横格线是别的勾形图标没有的Memo语境，不撞脸
  • 落地面最广：iOS / Android / monochrome / splash 同一形体通吃

风险

  • 与现行版隐喻断层最大，商店里是「换脸」
  • 勾形笔触走向需在 1024 稿上再打磨弧度（此处为方向示意）

口袋收条

唯一深底 · 表达「收下」

论点：说一声，它收进口袋。整个提案里唯一的大胆尝试：深墨底上一只暖色口袋，一张白卡正插进去，卡上那笔橙勾已经打好。这是产品核心动作「3 秒收下任何事」的静帧——别的方向说「记好了」，这个方向说「正在替你收着」。

优势

  • 深墨底在一片浅色壁纸里存在感最强
  • 「口袋」直接呼应产品名「口袋里的外置秘书」
  • 与 App 内暖纸 UI 形成内外互文：图标是深色「外套」

风险

  • 口袋 + 卡 + 勾三层结构，29px 位退化为「深底白块」
  • 深底图标与浅色系统主题并排时偏重
  • 形体最多，切图与 monochrome 派生成本最高

手书墨勾

最有人味 · 主人的笔迹

论点：这是主人亲手落下的笔。斜贴的白纸条上，一枝墨色手书勾——短臂粗、长臂细，是钢笔收锋的力道；句尾一枚橙点，像记完账画的句号。「主人的备忘录」的口吻由此而来：不是工具的 UI，是被记下的痕迹本身。

优势

  • 墨 + 纸的「手写」质感在图标里罕见，区隔度最高
  • 那枚橙句点是全提案最小的大胆尝试：一处点睛，全局克制
  • 纸条微倾带来松弛感，与 App「零摩擦」气质一致

风险

  • 墨勾 + 橙点在 29px 位会糊成一个深色图形
  • 斜构图的视觉重心需要逐尺寸校准
  • 手书笔触对最终 1024 稿的曲线质量要求最高

推荐：方向二「一勾即安」，方向四作备选

推荐理由：图标的第一战场是主屏 60px 与通知 29px，「一勾即安」是四个方向里唯一在所有缩放位都稳的；同时它把「格线纸」这个 Memo 语汇带进了勾形图标，避开了与系统备忘录的撞脸。备选「手书墨勾」——如果更想强调「主人的笔迹」这层人味，它是更性格化的选择，但需要接受 29px 位的衰减。
