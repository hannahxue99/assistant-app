# 三主页面视觉系统与小知品牌形象

状态：2026-09-25 用户已在 iPhone 17 / iOS 26.6.2 的“私人助手 Dev”中完成视觉验收；关联 PR [#34](https://github.com/hannahxue99/assistant-app/pull/34) 与后续比例修订 PR [#35](https://github.com/hannahxue99/assistant-app/pull/35)。

## 最终产品决策

- 首页、小知、我的统一使用纯白底，不叠加暖色氛围层。
- 首页保留问候、小知和“有我在，一切井井有条”；“本周待办｜全部待办”在同一位置切换，“小知正在关注”直接展示完整事件列表，不再拆出重点或最近事件。
- 待办卡内部紧凑，卡片与上下标题之间保留清晰留白；事件卡使用更大文字和按内容匹配的语义图标。
- 小知回复和“已处理”回执仍是两张独立卡，但宽度、白底、边框、圆角、阴影一致并左对齐。
- 我的页副标题保持单行，长期记忆上移，三个设置分组统一复用同一卡片与行样式。
- 三页右上角使用同一张 3D 小知资产。底部中间 Tab 删除文字，固定图标底边；选中态只向上放大，避免缩放时下沉或被裁切。
- 首页待办卡与事件卡共享相同左右边界。长期记忆类别行以设置行为基准：32×32 图标底、19 点图标、16 点标题字号、14 点卡片横向内边距；类别标题保留橙色和粗体。
- 首页本周待办的日期标签统一为日期在前：今天显示 `M/D 今天`，明天显示 `M/D 明天`，后续日期显示 `M/D 周X`，避免在窄标签列同时堆叠相对日期、具体日期和星期。

## 实现与数据边界

本次只替换 React Native 视图层、样式和静态图片，不改变页面的数据所有权。待办、事件、记忆、设置和对话仍从原 SQLite 与领域模块读取，完成、置顶、编辑、删除、同步、备份及聊天行为继续走原有流程。

`XiaozhiMascot` 对本地图片同时设置 `source` 与 `defaultSource`，并关闭原生淡入。这样 Tab 页面挂载或原生图片视图重新附着时，先显示同一张本地占位图，不出现空白帧。底部 Tab 保持固定布局尺寸，只对内部图像做以底边为原点的缩放。

## 边界与取舍

- 不把示例数据、组件预览或决策日志入口放进用户导航；内部调试页仍可保留，但入口不存在或必须受 `__DEV__` 守卫。
- 小知图片是 512×512、带透明通道的本地 PNG，不增加网络加载与离线风险。
- 页面状态、数据库 schema、原生依赖、权限和 Bundle ID 均未变化；Release 可覆盖安装并保留生产数据，不需要迁移。
- 相邻模块需要视觉对齐时，应复用同一组尺寸和边距 token，而不是只凭观感分别微调。PR #35 中记忆卡最终直接采用设置行的图标底、图标、字号和横向内边距基准，避免 2～6 点的小偏差在真机上被放大。
- 三张生成图保存在 `docs/plans/generated-design-reference/` 作为方向来源；真机验收后的细节以当前代码和设计说明为准。

## 回滚

代码回滚优先分别 revert PR #35 或 PR #34 的 GitHub 合并提交，不重写 `main` 历史。两次变更均无数据库迁移，回滚界面不会删除或降级用户数据；静态图片与样式可随代码一并回退。
