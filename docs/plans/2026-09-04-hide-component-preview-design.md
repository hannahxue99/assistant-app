# 隐藏组件预览入口设计

日期：2026-09-04  
状态：已确认

## 决策

- “我的”页面在测试 App 和正式 App 中都不展示“组件预览”。
- 页面内容在“统计”行结束，不暴露开发工具入口。
- `app/design-system.tsx` 页面保留，供开发者通过内部路由进行组件排查；本次不删除设计系统能力。
- 不影响 LLM 设置、画像、通知、导入、导出和统计功能。

## 验收标准

- Debug Dev Client 的“我的”页面不显示“组件预览”。
- Release App 的“我的”页面不显示“组件预览”。
- 内部 `/design-system` 页面代码仍保留。
