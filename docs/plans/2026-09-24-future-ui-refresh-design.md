# 三主页面轻未来视觉重构设计

## 目标

在不新增、删除或改写任何产品功能的前提下，统一首页、小知、我的三页视觉语言，让产品从“暖色卡片工具”转向“安静、精密、具有环境智能感的私人助手”。

视觉基准见 [`design/future-ui-refresh-v1.svg`](../../design/future-ui-refresh-v1.svg)。

## 最终方向

- 以雾白页面、墨黑正文、石墨灰辅助信息为主体。
- 以极淡的多色细线“认知轨道”作为环境背景，不承载点击或业务状态。
- 小知双眼是唯一饱和人格色；中央大球体取消，双眼只出现在标题、输入区和底部导航。
- 使用更明确的页面标题、编号/时间元数据和细分隔线建立层级，减少完整描边卡片。
- 控件选中态以墨黑为主，橙色只用于小知人格、处理中提示和少量温暖状态。

## 页面范围

### 首页

保留且仅保留：日期、本周待办/全部待办切换、待办行、事件区。待办由卡片改为带细分隔线的排版行；事件保留标题、当前状态、更新时间和置顶。空态、加载态、错误态和待办定位高亮继续存在。

### 小知

保留且仅保留：标题与连续对话说明、配置/上下文提示、消息、推理与运行状态、来源、操作回执、输入区、停止和置底。取消中央球体；轨道只在标题下方作为低透明度背景，不占内容高度。用户消息使用墨黑紧凑气泡；小知回复继续使用现有受控 Markdown 和页面内容流。

### 我的

保留且仅保留：长期记忆、陪伴/条数摘要、记忆修改与忘记、助手与同步、待办通知、数据管理。长期记忆使用编号式内容列表；设置继续分组，不新增画像、建议或分析。

## 数据流与兼容性

没有数据层变化。SQLite schema、查询、模型调用、事件/待办/记忆关系、通知、日历、导入导出、Dev/Release Bundle ID 均保持不变。现有组件 props 和页面行为优先原样保留，视觉元素不得成为新的业务状态来源。

## 边界情况

- 空、加载、错误、禁用与长文本状态仍可读，不依赖背景轨道表达信息。
- 动态字体和窄屏下正文不得与固定宽度编号/图标重叠。
- 所有现有可点击区域继续满足最小 44×44pt。
- 小知的 following/history、键盘同帧位移、较早消息加载、停止与重试不得因视觉布局改变而退化。
- Reduce Motion 开启时，双眼沿用现有静止行为；背景轨道不新增常驻动画。

## 验收标准

1. 三页与视觉基准形成同一套雾白、墨黑、细线和橙色双眼语言。
2. 小知页没有中央球体或占位式英雄区域，首屏消息容量不低于当前版本。
3. 首页、我的页没有新增入口或产品文案，现有操作可达性保持不变。
4. 加载、空、错误、选中、禁用、处理和编辑状态均能辨认。
5. `npm run test:assistant-layout`、相关 UI 测试、类型检查和 `npm run ci` 通过。
6. GitHub `CI / validate` 通过后，由目标分支 Metro tunnel 在“私人助手 Dev”完成三页真机 Reload 验收。
