# 设置分组与小知双眼图标设计

## 目标

在不改变任何设置业务逻辑的前提下，收紧“我的”页面的信息归组，并用更简洁、有生命感的双眼动效替换当前机器人 Tab 图标。

视觉稿：[设置分组 + 小知眼睛动效](../../design/profile-settings-xiaozhi-eyes-v19.svg)

## 页面调整

### 助手与同步

“理解引擎”和“同步到苹果日历”放入同一张圆角卡片。两行共用边框与背景，中间使用与“导出数据 / 导入数据”一致的 `StyleSheet.hairlineWidth` 横线。

- 第一行：理解引擎，保留当前状态与进入配置页的箭头。
- 第二行：同步到苹果日历，保留开关、授权确认、账户选择和同步状态。
- 日历的补充状态默认显示在第二行标题下；有错误时，错误内容及“重试 / 去设置”在第二行内部展开，不形成第三张卡。

### 待办通知

晨间和夜间开关继续放在同一张卡片，中间增加同样的发丝横线。两行高度、左右内边距与助手设置卡保持一致，开关逻辑和通知时间不变。

## 小知双眼图标

采用“眼睛本身就是角色”的方向，不画机器人头、天线或嘴巴。参考成熟 AI 助手图标常见的“大眼、圆角、强识别”原则，但重新按当前产品暖色、轻量 Tab 尺寸设计。

### 视觉与动效

- 形态：一个宽高基本一致、接近圆形的极浅色小脸，内部两枚小号、略圆且稍微靠上的短椭圆眼睛；眼睛只占小脸较小面积，四周和下方留出明显空间，不使用横向胶囊比例。
- 常驻颜色：小脸底色和眼睛始终使用品牌暖橙体系，不随 Tab 是否选中变灰；只保留“小知”文字的深浅变化作为当前位置反馈。
- 注视：两个眼睛同步左右或轻微上下偏移 2–3 px；每次移动后停留 1.8–2.8 秒，不连续抖动。
- 眨眼：每 5–8 秒随机一次，将眼睛纵向压缩后恢复，约 160ms。
- 生命周期：仅在 App 前台运行；系统开启“减少动态效果”时保持静态；组件卸载时取消定时器和动画。
- 语义：该动效只表达“小知在这里”，不表达录音、联网或模型正在处理。实际处理状态仍由对话页负责。

### 底部导航选中状态

状态对照稿：[全橙色底部导航](../../design/bottom-tabs-orange-states-v20.svg)

- 三个 Tab 的图标和文字始终使用品牌暖橙，不再通过橙色 / 灰色表达选中状态。
- 首页：未选中使用 `home-outline`，选中使用 `home`；图标尺寸保持不变。
- 我的：未选中使用 `person-outline`，选中使用 `person`；图标尺寸保持不变。
- 小知：未选中小脸为 30pt，选中为 34pt；眼睛和浅橙底的比例随整体等比变化。
- 小知外层使用固定 36pt 槽位，大小切换只发生在内部，Tab 文字和底栏高度不移动。
- 扫视和眨眼在两种大小下都继续运行；切换选中态不会重启动画计时器。

## 实现方案

1. 将 `CalendarSyncSetting` 改为可嵌入的设置行，由“我的”页面提供共同卡片外框和分隔线。
2. 抽出统一的 `settingsCard / settingsRow / settingsDivider` 样式，使助手同步、待办通知、数据管理使用同一种分组语言。
3. 新建 `XiaozhiEyesIcon`，使用 React Native 原生驱动动画完成瞳孔位移和眨眼；不引入图片或新原生依赖。
4. Tab 传入 `focused / size`，组件负责 30pt / 34pt 尺寸切换与动效；导航图标和文字统一使用品牌暖橙，可访问性名称仍由 Tab 标签提供。

## 数据流变化

无数据库、模型、日历或通知数据流变化。本轮仅重组现有组件层级和替换 Tab 图标。日历状态仍由 `calendarStatus()` 读取，开关仍调用 `setCalendarEnabled()` 和 `syncCalendar()`。

## 边界情况

- Android 不展示苹果日历行时，助手卡只保留理解引擎一行，不显示孤立分隔线。
- 日历状态读取中，开关保持禁用；卡片高度允许补充说明展开。
- 页面滚动或切换 Tab 不重置设置状态。
- App 退到后台、系统减少动态效果、组件卸载时，眼睛不继续消耗动画资源。
- 快速反复切换 Tab 不创建叠加计时器。

## 验收标准

1. iOS“助手与同步”只有一张卡，理解引擎和苹果日历之间有横线。
2. “待办通知”两行之间有横线，开关状态及通知逻辑不变。
3. 数据管理现有分组样式不回退。
4. 底部“小知”不再显示机器人图标，而是接近圆形的小脸和两只同步微动、偶尔眨眼的眼睛，不能呈扁平胶囊状。
5. 选中和未选中时图标都保持暖橙，只有“小知”文字按 Tab 状态改变深浅；图标和文字不发生布局跳动。
6. 系统减少动态效果或 App 进入后台后，图标静止；返回前台恢复。
7. `npm run ci` 通过，Dev 版 Metro Reload 后可验收，无需重装。
8. 首页和我的在选中时为实心、未选中时为空心，尺寸和位置不变；小知未选中为 30pt、选中为 34pt，切换时底栏不跳动。
