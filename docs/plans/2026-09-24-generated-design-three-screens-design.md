# 三张生成图视觉落地设计

## 目标

以原 ChatGPT 对话实际生成的三张成品图为唯一视觉基准，重做首页、我的、小知聊天页。保留现有功能、SQLite 数据、导航结构、聊天滚动及键盘行为，不扩展产品范围。

## 视觉基准

- `generated-design-reference/home.png`：首页。
- `generated-design-reference/profile.png`：我的。
- `generated-design-reference/assistant.png`：小知聊天页。
- 暖白底叠加极浅橙色氛围；白色圆角卡片使用柔和阴影，减少硬描边。
- 品牌橙只用于主动作、选中态、重点时间和小知形象。
- 页面统一使用 20pt 横向留白、16/20pt 两档圆角、明确的标题/正文/辅助文字层级。
- 复用同一张透明背景 3D 小知形象，首页、我的和聊天页只调整尺寸与位置。

## 页面设计

### 首页

顶部显示随时间变化的问候、当天日期和小知形象。主体依次为“今日待办”“小知正在关注”“最近事件”：待办与最近事件使用白色分组卡；关注区域使用淡橙重点卡。现有待办、事件详情跳转、完成待办和查看更多交互全部保留。

### 我的

顶部保留标题、说明、小知形象与对话气泡。长期记忆继续展示真实记忆数据，卡片补充语义图标、日期、编辑及删除操作。原有理解引擎、联网搜索、日历同步、晨间/夜间通知、备份导入导出等设置保持可用，只重排为生成图中的白色分组卡。

### 小知

顶部显示标题、副标题和小知形象。助手长回复使用淡暖色内容卡，普通助手消息使用带头像的白色卡，用户消息保持橙色气泡；推理耗时弱化。输入框保持当前可靠的键盘贴底、滚动和发送/中断逻辑，仅更新表面样式。

## 实现方式

- 在 `src/components/` 新增复用背景氛围与小知品牌形象组件。
- 扩展 `src/theme.ts` 为三页共用的暖色设计令牌。
- 在三个 Tab 页面内复用当前查询、更新和导航逻辑，只替换布局与样式。
- 底部 Tab 保留 Expo Router 导航，统一选中/未选中颜色、图标和高度。
- 不引入新的原生依赖；图片使用 React Native 静态资源加载。

## 数据流

SQLite 与现有领域模块仍是唯一数据源。页面聚焦时继续读取待办、事件、记忆和设置；用户操作继续调用原有完成、编辑、删除、同步、通知及备份流程。新增视觉组件只消费展示数据，不缓存、改写或复制业务状态。

## 边界情况

- 无待办、无事件、无记忆时保留可操作的空状态，不伪造生成图示例数据。
- 文本过长时限制行数或自然换行，不能撑破卡片和操作按钮。
- 小屏设备、底部安全区和键盘弹出时保持内容可达。
- 加载、失败、重试、流式回复、发送中断和撤销记忆保持原行为。
- 动态日期、通知关闭态和日历未授权态必须显示真实状态。

## 验收标准

1. 三个主页面的结构、暖色氛围、卡片层级、3D 小知形象和底部导航与三张基准图一致。
2. 首页所有真实待办/事件能正确展示、完成和跳转。
3. 我的页记忆编辑、删除、撤销及全部设置能力可用。
4. 小知页历史消息、Markdown、来源、动作回执、流式回复、重试、中断、键盘贴底和滚动行为无回归。
5. 不出现仅供预览的示例数据、入口或开发文案。
6. 新增回归检查进入聚合 `npm test`，类型检查和 `npm run ci` 通过。
