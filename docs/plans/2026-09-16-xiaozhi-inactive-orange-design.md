# 小知未选中态橙色修正

## 问题

当前未选中态使用 `accentSoft`（`#F9E8DD`）作为脸部填充。在真机底部导航的小尺寸和系统背景衬托下，它会呈现成偏灰的低饱和色，与“小知始终保持橙色”的既定规则不符。

## 设计

- 未选中：脸部使用品牌橙 `#E0733A`，眼睛使用暖白 `#FFF7F2`，尺寸维持 30pt。
- 选中：脸部同样使用品牌橙 `#E0733A`，眼睛同样使用暖白，尺寸为 38pt，并上移 3pt。
- 选中状态只通过“放大 + 上移”表达，不再使用颜色变化，避免未选中态再次看起来发灰。
- 眼睛的移动频率、幅度保持上一轮已确认值。

## 实现范围

仅修改 `XiaozhiEyesIcon` 的未选中颜色分支；不改导航结构、尺寸、动画、点击区域或其他 Tab。

## 验收标准

1. 首页或“我的”选中时，小知未选中脸部仍明显为品牌橙。
2. 小知选中时通过更大且上移区分，颜色不跳变。
3. 两个状态的眼睛均为暖白，动画连续。
4. Metro Reload 即可生效，不需重装 Dev App。
