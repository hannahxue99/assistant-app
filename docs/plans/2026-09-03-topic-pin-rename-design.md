# 聚合消息置顶与主题改名设计

## 目标

聚合主题支持置顶、取消置顶和改名，同时保持条目历史、搜索及后续 LLM 聚合逻辑一致。

## 排序与交互

- 置顶主题统一排在普通主题之前。
- 多个置顶主题按最近置顶时间倒序；普通主题按最新消息时间倒序。
- 取消置顶后，主题回到普通主题的时间顺序。
- 聚合卡使用苹果风格的经典斜图钉直接切换状态：最终视觉为钉帽右上、钉尖左下；当前 Ionicons 字形实现层旋转 45°。线框表示未置顶、实心表示已置顶；图标视觉 18px、点击区 44×44。点击区绝对定位，不参与标题行布局。置顶态仅使用轻金色描边和背景。
- 聚合详情页在主题旁显示铅笔入口，进入行内编辑；空名称不可保存。
- 全 App 编辑入口统一为 `pencil-outline → 完成`：页面级图标 20px/文字 15px，模块级图标 18px/文字 13px，字号随模块适配但交互语义不变。
- 改成已存在主题时明确提示将发生合并，确认后才执行。

## 数据与一致性

主题置顶属于主题级显示偏好，保存在 `topic_preferences(topic, pinned_at)`，不重复写进每条 `entries`。主题改名会批量修改该组所有 `entries.topic`。改名与置顶偏好迁移在独占 SQLite 事务内完成；发生同名合并时保留两组中较新的置顶时间。

## 验证

纯函数测试覆盖置顶优先级、多个置顶顺序和普通主题顺序；类型检查覆盖页面、SQLite API 与路由调用。手工验收覆盖置顶、取消、图钉方向、卡片紧凑度、改成新主题、改成已有主题并合并。
