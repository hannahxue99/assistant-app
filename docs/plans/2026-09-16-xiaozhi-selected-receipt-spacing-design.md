# 小知选中态与操作回执间距修正

## 范围确认

“推送卡片”按小知回复下方、带“已处理 / 撤销本轮”的操作回执卡片理解。

## 设计

### 小知图标

- 未选中维持 30pt、正常位置、品牌橙脸和暖白眼睛。
- 选中由 34pt 增大为 38pt，仍上移 3pt。
- 颜色与动画不变，避免状态切换时颜色闪动。

### 操作回执卡片

- 卡片上下内边距统一为 6pt。
- 标题区视觉高度 26pt；标题区与第一行不额外留白。
- 单行操作不再强制 44pt 的可见高度，视觉行高约 28–32pt；通过外部点击区域和 `hitSlop` 保持可点击性。
- 同一操作内的多行说明间距压缩到 0–1pt。
- 不同操作之间只保留 2pt 间距，不再使用当前每行 44pt 造成的大块留白。
- 左右内边距、字体、图标、撤销逻辑和跳转逻辑保持不变。

## 验收标准

1. 选中小知比未选中明显更大，但不挤压文字或 Tab 高度。
2. 两个及以上操作在同一卡片内展示时，行与行紧凑但仍能辨识。
3. 卡片顶部和底部空白视觉一致。
4. 单行、多行、带撤销错误三种状态均无裁切。
5. Metro Reload 生效，不需要重装。

## 内容状态规则

- 单条待办：一行；可见待办带跳转箭头，无日期隐藏待办不带。
- 同一事件的状态更新与关键进展：合成一个操作组，组内多行间距 0–1pt，只保留一个事件跳转箭头。
- 事件与待办：属于两个对象，分成两条操作行，间距 2pt，各自跳转。
- 长期记忆：单独一行，跳转“我的－长期记忆”。
- 删除：对象已经不可见，不提供无效跳转；回执保留撤销入口。级联删除的数量作为第二行说明。
- 已撤销：标题改为“已撤销”，图标与文字变灰并划线，不再展示撤销按钮。
- 无法撤销：保留原操作内容，在卡片底部紧凑展示冲突原因。
