# 小知输入区单层设计

## 决策

小知页底部只保留圆角输入框这一个可见层级。移除输入框外层底栏的顶部分隔线和显式背景，但保留水平与底部间距。

视觉对比：[xiaozhi-composer-single-layer-v29.svg](../../design/xiaozhi-composer-single-layer-v29.svg)

## 实现边界

- 不改动 `AssistantComposer` 本身的高度、圆角、边框或阴影。
- 不改动语音输入、波动条、发送、停止、错误提示和处理中状态。
- 不改动 `KeyboardAvoidingView` 与底部 Tab 安全间距。
- 消息列表不改为悬浮覆盖式，避免最后一条消息被遮挡。

## 验收标准

1. 页面底部不再出现横向分隔线或独立底栏色块。
2. 只有圆角输入框作为可见容器。
3. 键盘弹出、多行输入、语音输入和运行中停止均保持原行为。
