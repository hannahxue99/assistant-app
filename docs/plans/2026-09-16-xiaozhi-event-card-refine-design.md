# 小知选中位置与首页事件第二行字号

## 设计

- 小知选中态维持 38pt 和品牌橙，将纵向位置从上移 3pt 调整为上移 5pt。
- 未选中态位置、图标尺寸、眼睛动画、Tab 高度和标签位置不变。
- 首页事件卡片第二行“当前状态”从 13pt / 19pt 行高调整为 14pt / 20pt 行高。
- 事件标题、时间戳、卡片内边距、三行间距和置顶按钮均保持不变。

## 验收标准

1. 小知选中后与标签的间距更明显，但图标不碰到 Tab 顶部。
2. 首页事件第二行比时间戳明显、比标题略弱，长内容仍保持单行省略。
3. 卡片高度没有明显增加，列表密度不变。
4. Metro Reload 生效，无需重装。
