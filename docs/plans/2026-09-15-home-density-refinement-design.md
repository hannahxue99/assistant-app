# 首页待办 Tab 与事件卡密度微调

状态：已确认并实施，等待 Dev 真机验收

视觉稿：[Before / After](../../design/home-density-refinement-v14.svg)

## 方案选择

采用方案 A：固定 Tab 几何，只改变文字颜色。`本周待办` 与 `全部待办` 的字号、字重、坐标和 44px 点击区域在选中前后都保持不变；移除短橙色下划线。选中项使用正文色 `#2B2622`，未选中项改为更浅的 `#A9A29A`，分隔符维持弱灰。这样点击时不会发生上下或横向跳动，同时仍能明确识别当前列表。

备选方案 B 是颜色加字重变化，但字重变化可能造成字符宽度轻微变化，不采用。备选方案 C 是增加浅色背景块，状态更强，但会把标题做成分段控件，视觉过重，也不符合本次“只用深浅”的反馈。

事件卡保留标题、进展、时间三行，但不再用固定最小高度或 `space-between` 撑开。改为由内容自然撑高：目标高度约 86–90px，水平内边距 12px、垂直内边距 10px，三行间距 3px。标题、进展仍各最多一行；无进展时仍显示占位内容，所以卡片之间高度稳定。右上 44px 置顶热区、颜色、排序与跳转逻辑不变。

## 实施与数据流

只修改首页 Tab 样式和 `AssistantEventCard` 布局样式，不修改组件状态、待办查询、7 天边界、回执定位、事件排序或 SQLite 数据。Tab 切换后仍加载原列表；事件卡点击和置顶仍走现有处理函数。

## 边界与验收

1. 连续点击两个 Tab，所有文字在屏幕上的纵向位置完全不变，不出现下划线。
2. 选中和未选中只通过深浅区分；两项可点击区域仍不少于 44px。
3. 事件卡仍稳定显示三行，卡高约 86–90px，底部没有固定高度造成的多余空白。
4. 动态字体、长标题、无进展、置顶及按压状态不破坏三行结构。
5. 不产生数据库迁移或原生变更；通过 TypeScript、现有 UI/数据库测试和 `npm run ci` 后，用原 Metro 会话 Reload Dev 包。
