# 小知键盘、贴底与返回路径实施计划

1. 在小知 UI 状态模块加入刷新贴底策略和布局变化判断，并补纯函数回归测试。
2. 将 iOS 键盘避让改为缩短有效高度，保留绝对定位的悬浮输入框与真实尾部占位。
3. 用 `following / history` 单一模式替代多组重叠布尔状态；键盘、布局和流式回复都读取这一模式。
4. 用同一份距离末端计算驱动贴底判断、置底按钮和白色渐隐/阴影强度。
5. 增加输入框上方的圆形置底按钮；历史位置唤起键盘时不滚动，只有按钮或明确发送才回到底部。
6. 回复完成、停止和重试改为条件贴底，修复主动上翻后被拉回的问题。
7. 统一小知内部跳转的键盘收起与返回位置保护；来源网页打开前收起键盘。
8. 修正从小知进入理解引擎时不准确的返回文案。
9. 运行小知布局、UI、输入框测试和类型检查，真机验收四种滚动场景后再运行聚合 CI 并推送到现有 PR #31。
